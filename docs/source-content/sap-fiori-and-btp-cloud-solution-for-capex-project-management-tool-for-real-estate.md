# SAP Fiori and BTP Cloud solution for CAPEX Project management tool for Real Estate
SAP Fiori and BTP Cloud solution streamlines CAPEX project management for real estate, enabling efficient tracking and control.
[image: https://adamastechconsulting.com/wp-content/uploads/2024/09/Frame-2883.png | alt=""]
## Business Overview
- One of the largest European University has multiple real state infrastructure within their campuses. Every Infrastructure is treated a CAPEX project which needed budget planning, tracking and end to end execution cycle. The Campus board members wanted to harmonize all these expense sheet in the form of a project management tool which can be accessed over any user devices like desktop, mobile, tablets or web.
- All the expense sheets, claims and other expense data were maintained in excel. It was tedious job to update it every time once any new decision were taken. Also, it was very complex to manage the project progress based on assignments.
## Solutions Offered
### Enterprise Planning
The university leverages SAP S/4HANA for robust enterprise resource planning, including project systems capabilities tailored for CAPEX operations.
### Cloud Integration
SAP Business Technology Platform (SAP BTP) provided integration with cloud mobility solutions for seamless access and scalability across different devices.
### User-Centric Design
Provided a modern, user-friendly interface for accessing SAP applications, ensuring intuitive user experiences and efficient workflows.
### Key features:
- Dashboard overview
- Budget Planning and Tracking
- Procurement and Resource planning
- Project Execution and monitoring
- Reporting and Analytics
- Mobile Accessibility (responsive design and offline capability)
## Technologies Leveraged
- SAP S4HANA Projects Systems, MM, SD
- SAP BTP Mobility Solutions
- SAP Fiori Web Applications
