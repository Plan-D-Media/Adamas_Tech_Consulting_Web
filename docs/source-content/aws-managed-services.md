## Service Overview
## AWS Managed Services
A managed service provider (MSP) takes ongoing responsibility for running and supporting a piece of a customer’s technology — monitoring it, maintaining it, and resolving problems as they come up — so the customer’s own team doesn’t have to carry that load. / An AWS MSP does this specifically for infrastructure running on Amazon Web Services. Instead of your team owning day-to-day operations — patching, monitoring, incident response, backups, cost tracking — an AWS MSP takes that on, following AWS’s own recommended operational practices, while your team stays focused on the applications and features that actually move your business forward.
## Why businesses work with an AWS MSP
Running AWS well is a full-time discipline, not a side task for an already-stretched engineering team.
